# Development Process

## Process Model

The College Assignment Tracker project uses Scrum as its Agile development process. Scrum allows the project to be developed incrementally by organizing features into a prioritized product backlog and completing selected work during sprints.

## Scrum Board

The project is managed using GitHub Projects.

[College Assignment Tracker - Scrum Board](https://github.com/users/Aden-Bailey/projects/2)

The board contains three workflow stages:

- Backlog
- In Progress
- Done

## Sprint 1

**Sprint Length:** 2 weeks (September 25 - October 8)

**Sprint Goal:** Develop the core functionality of the College Assignment Tracker so a student can create, manage, and track assignments.

### Sprint 1 Backlog

1. Add assignments
2. Enter assignment due dates
3. Edit assignments
4. Delete assignments
5. Mark assignments as completed

The remaining product backlog items will be considered for future sprints.
