# College Assignment Tracker

## Team Member
Aden Bailey

## Project Abstract
College Assignment Tracker is a web application designed to be a way for college students to easily track their school assignments. Users will be able to add an assignment with course name, assignment name, due date, and completion status. They will also be able to view their assignments, mark them as complete, edit them, and delete them. The goal of this project is to create a simple and useful application that makes it easier for students to organize their coursework and keep track of assignments.
